# SeeZMemo（店家大頭針）V0.1.1

一款先拍、先存，之後再整理的 iPhone 店家踩點工具。看到美食店家或特殊販賣物店家時，拍下招牌即可建立含照片、位置與時間的草稿。

## 目前功能

- 首頁紅色玻璃相機按鈕可直接拍攝；右上角「＋」可跳過相機建立空白紀錄
- 每筆最多 10 張照片，可拍照、匯入、刪除及設為首張；新拍照片同步保存到手機相簿
- 自動取得座標、最近門牌與國家；相簿原始照片的 GPS 會在壓縮前獨立保存
- 修正位置可載入首張照片 GPS，或用地址欄右側放大鏡重新定位；鄰近搜尋結果以紅色座標提示
- Vision OCR「拍照辨識」支援繁體中文、英文、日文及韓文
- 類型記憶顯示最常用前三個、最新一個與其餘類型下拉選單
- 店家名稱、類型、資料、到遊心得、位置、國家、紀錄時間與拜訪時間
- 草稿快速暫存、首頁收合區續編，以及全部紀錄查看、搜尋、編輯與刪除
- 全部紀錄可依時間、名稱筆畫、國家筆畫或使用者距離排序，並可切換清單／地圖
- 首頁附近地圖預設 2 公里，可在當次執行暫時改範圍並切換距離清單
- 首頁地圖標籤可複製地址並開啟 Google Maps 路線
- 「喵仔流水帳」以首張優先順序分享文字與照片；分享照片長邊不超過 2048 像素且低於 500 KB
- 所有表單提供完成鍵、鍵盤右側「隱藏鍵盤」、空白點擊及捲動收鍵盤
- 首頁版本以 `V#.#.#(YYYYMMDD)` 顯示；設定頁提供程式設計者，以及上下兩行顯示的使用回饋信箱
- 完全離線的 SwiftData 本機資料保存，新增欄位相容 V0.0.1 既有紀錄

## 開發環境

- Swift 5
- SwiftUI / SwiftData / MapKit / Vision / PhotosUI
- 最低版本 iOS 18.0
- 目標裝置 iPhone 16、iPhone 17 Pro

開啟 `SeeZMemo.xcodeproj`，選擇 iPhone 模擬器或已簽署的實機後執行。首次使用相機、相簿及定位時，系統會詢問權限。

## 專案結構

- `SeeZMemo/`：App 原始碼與資源
- `SeeZMemoTests/`：核心規則測試
- `Preview/`：操作預覽產生器與網頁索引
- `renders/`：iPhone 16、iPhone 17 Pro 頁面渲染圖及實際模擬器截圖
- `docs/`：操作流程、驗證紀錄與產品路線
